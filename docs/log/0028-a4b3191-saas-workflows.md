# a4b3191 用户流程、独立 Demo 与导出

对应提交：`a4b3191 feat(saas): complete patient workflows and isolated demo`。

本轮补齐从录入到复诊查看之间的缺口：化验支持多文件审核队列、未知指标纠正、重复确认和保存重试；初次建档失败可以独立重试保存；总览通过摘要分页展示本人全部病历。邮箱确认、找回密码和错误回调均有明确恢复入口，账户切换后不会继续旧账号的敏感操作。

账户 JSON 导出补齐随访、症状、用量、权益与捐赠资料，保持分页和身份绑定。错误上报仅保留允许的诊断字段，避免把病历内容、URL 参数与凭据发往上报服务。

公开 Demo 使用三类虚构患者和独立内存状态，共用正式产品页面。编辑、化验、随访和症状修改可以跨页查看，刷新后恢复示例；真实认证、数据库、模型、支付和账户删除保持隔离。

实际浏览器验收暴露了旧导出库不支持现代颜色、分页裁字和纯白尾页的问题。导出采用 html2canvas-pro，固定白底文档副本，保留页边距、按正文分页并压缩输出；末页只移除没有绘制内容的尾部。

## 验证

- lint、完整类型检查、93 文件 / 669 项全量测试、覆盖率与生产构建通过。随后空白尾页修复另通过 11 项导出回归、相关类型/lint 和构建；不把两次结果相加当作一次全量测试。
- 真实浏览器从错误回调页重新登录独立测试后端，进入包含 12 份合成病历的总览；列表首批 10 条、下一批 2 条，390px 窄屏内容可读。
- 合成随访保存后刷新仍可读，账户 JSON 已实际下载并核对记录数量与敏感字段排除。
- 生产构建中的 Demo 验证跨页编辑、逐份保存两份化验、总览读数 27 → 31，以及刷新恢复 27。
- 桌面深色长病历导出 PNG 和 3 页 PDF，390px 浅色 Demo 导出 2 页 PDF；最终文件逐页查看，正文完整且没有空白尾页。

证据置信度：高。浏览器验收使用独立本地后端和虚构资料，未调用真实模型/OCR/支付；新设计布局尚待用户选择，正式页面没有完成视觉迁移。完整功能与上线边界见 `docs/products/saas-acceptance.md`。
