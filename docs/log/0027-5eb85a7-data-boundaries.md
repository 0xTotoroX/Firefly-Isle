# 5eb85a7 数据权限与原子写入

对应提交：`5eb85a7 fix(data): enforce API grants and atomic write boundaries`。

完整本地 Supabase 验收发现，新数据库不一定自动向 Data API 授予表权限：账号可以注册，但病历与资料查询仍失败。新增迁移显式声明表、列和 RPC 的最小授权，保留 RLS 行隔离；公开访问只开放分享 RPC，分享更新仅允许撤销列，账本仍为客户端只读。

新病历草稿使用固定请求 UUID。第一次提交成功但响应丢失时，重试返回同一病历；并发提交不重复建档，也不覆盖提交后的编辑。已有病历更新与旧两参数 RPC 继续兼容。

捐赠 webhook 只把明确付款事实交给服务端专用 RPC，按 Checkout Session 原子记账。未付款的完成事件保持待支付；重复和晚到事件不能降级付款状态，注销后的收据不能重新关联账号。Supabase 配置仅对 Stripe webhook 关闭 JWT 前置检查，原始正文签名仍由 handler 验证。
