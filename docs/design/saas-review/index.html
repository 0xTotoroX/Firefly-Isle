中文与数字规则

  • 正文使用系统中文字体；长段落宽度不超过 720 px。
  • 病程、药名、剂量和错误原因不省略。次要元数据才允许截断，并提供展开入口。
  • 日期固定为 2026-09-20；数据列使用等宽数字，单位独立显示。
  • 保留原报告的小数精度；未记录写“未记录”，不显示为 0。

响应式规则

  • 桌面 ≥1024 px：侧栏 224 px，内容最多 1280 px；阅读正文限制宽度。
  • 平板 640–1023 px：导航收为顶部，详情优先；表单保持单列或两列。
  • 手机 <640 px：边距 16 px、表单单列、按钮至少 44 × 44 px。
  • 数据表保留必要列并局部横向滚动，整页不横向溢出。
DS–04 / COMPONENT ANATOMY结构 · 行为 · 可访问性

组件与规则

每个组件需要明确的标签、当前状态和操作结果。默认状态足够简洁，出错时提供可执行的下一步。

2用日期和检查类型，方便下次查找。

此处可体验输入和即时反馈。

1

标签始终可见

标签与输入框绑定；占位文字只举例，不承担字段说明。

2

说明与错误紧靠字段

错误说明原因和修正方式。提交失败不清空内容，并将焦点移到首个错误字段。

3

主操作只有一个

保存中防止重复提交。完成后明确反馈；取消和返回保持较低视觉权重。

按钮与图标

常用操作使用图标加文字。图标 16–20 px、描边 1.5–2 px；纯图标按钮必须有可访问名称。危险操作放进确认步骤。

导航与焦点

Tab 按视觉顺序移动，Enter / 空格执行。选中项同时改变背景与文字；2 px 焦点环与控件相距 3 px，不被容器裁切。

提示与状态

徽章描述状态，不伪装成按钮。异步结果通过状态区域播报；错误保留到被处理，成功提示无需打断阅读。

检验数据表

数字对齐、单位明确，异常与来源同时可查。

页面内容优先级

默认展示患者身份、当前任务、关键日期和操作状态。来源详情、历史版本、技术参数按需展开。AI 建议与原始记录分区呈现，并保留“待核对”标识。

弹窗与撤销

弹窗提供标题与关闭入口，打开后焦点进入；Escape 关闭后焦点回到触发按钮。删除前说明影响，默认聚焦取消。
